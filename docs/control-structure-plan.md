# Control structures: a CRUD screen, a factory, and four ways out

**Moved to asi_kletz 0.24.0.** The owner, 2026-10-29: "control structures were supposed to go into Kletz and
not Dewey"; asked where STPA should live: "move everything to Kletz". The plan, its phases and its status live
in [asi_kletz/docs/control-structure-plan.md](../../asi_kletz/docs/control-structure-plan.md), the canonical
copy; asi_kletz's README ("What is in 0.24.0", "Control structures", "STPA analyses") describes what shipped.

What this plan built in asi_dewey (phase 2 in 0.9.0, phase 3 in 0.10.0, the STPA step objects of the Confluence
integration plan in 0.10.0 and 0.10.1) was removed in asi_dewey 0.11.0 under the rule the owner stated the same
day: "Dewey is more for experimental and day to day; all true work products will end up in Kletz once
sanitized." What remains here is `asi-dewey handover --out <dir>`, which writes the thirteen tables an older
database still holds in the shapes Kletz reads (the README, "Handing STPA work to Kletz"). This file stays so
that links to it resolve.
